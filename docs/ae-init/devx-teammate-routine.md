# ae-init: DevX teammate routine

> **Status:** Verified: routine `devx-teammate` is live
> **Last updated:** 2026-11-06
> **Routine:** https://claude.ai/code/routines/trig_01Hw8AenveTpbdvT8YoZqJkw

## What to build

A teammate that works on its own. Every weekday morning, a Claude Code cloud routine checks out andrelas6/ai-agent-go and picks the most useful missing piece of DevX or DevOps work. That means CI, quality gates, security checks, dependency updates or local dev tooling, never application logic. It builds that one piece on a `devx/*` branch, runs the checks, and opens a small PR for André to review and merge. It runs on the Max plan only, with no extra usage. It never pushes to main, never merges, never changes repo settings, and it waits while two of its PRs are still open.

## A -> B

- **A (now):** No routine for this repo. No `.github/` folder, so PRs get no CI. `main` is not protected. Dependabot security updates are off. Every DevX improvement only happens when André does it.
- **B (after):** `devx-teammate` fires weekdays at 06:00 UTC. Each run either opens one `devx/*` PR with green checks, pushes a fix to a failing open `devx/*` PR, or ends saying there's nothing worth doing.

## How to reproduce

**Preconditions**
- Max plan, extra usage OFF (claude.ai → Settings → Usage).
- Claude GitHub app can read and push to andrelas6/ai-agent-go.
- Cloud environment: Default (`env_01Y4sforcWCiAXFojDQfHJZo`), model `claude-sonnet-5-5`, no connectors.
- Routine prompt as stored on the routine (one PR per run, `devx/*` branches, pauses at 2 open).

**Steps**
1. `ls .github` in the repo and `gh pr list --state open` (A: no folder; no devx/ PRs).
2. `gh api repos/andrelas6/ai-agent-go/branches/main/protection` (A: 404 Branch not protected).
3. List routines at https://claude.ai/code/routines (A: no devx-teammate).
4. After creating it: press **Run now** once instead of waiting for 06:00.
5. Read the run with `list_runs` / `get_run_log`, then `gh pr list --head 'devx/'`.
6. Press **Run now** two more times on the same day to test the pause rule.

## Settled

- **Branch protection on main.** A `main` ruleset requires a PR, squash merge only, and the `check` job. It blocks force-push and deletion. Admin can bypass only through a PR, so nothing can push straight to main.
- **PR creation in the cloud.** It works through the session's GitHub tools, not `gh`. Pushes go through the Claude GitHub app.
- **Go 1.26.4 in the cloud image.** Works. Build and `test -race` ran in the sandbox.
- **Identity.** Commits are authored by `Claude <noreply@anthropic.com>`, which is kept on purpose: it marks what the automation wrote. PRs and comments post under André's account.
- **Footers.** PR descriptions have no footer. Comments and review replies keep the "Generated by Claude Code" footer, so the bot's replies stand apart from André's.
- **Other agents' branches.** The routine works only on its own `devx/*` branches. It leaves Dependabot PRs to André.

## Open questions

- **Daily run cap.** The docs give no number for Max (an older post said 15 a day). The three tests used three runs.
- **How long a run session stays subscribed to its PR.** Each scheduled run also answers comments it hasn't replied to yet, so nothing is missed if the subscription ends.
