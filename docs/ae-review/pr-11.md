# ae-review: PR #11 — feat: Subscribe after shutdown returns a closed stream

**problem being solved** before: `Subscribe` after shutdown returns a `nil` channel; anyone reading it blocks forever. after: it returns an already-closed channel, so the reader stops right away. README documents resume, cap and cut-off.

**opportunities to learn**
- nil channel blocks forever, closed channel returns at once with `ok == false`: returning a pre-closed channel is the idiomatic "nothing more will come". `internal/bus/bus.go:67-71`
- `ctx.Done()` in the same `select` as the send: once the owner goroutine is gone, `doneCh` is the only ready case, so no up-front check is needed. `bus.go:53-56`

**error handling**
- after shutdown the handler sends 200 with an empty body; `EventSource` retries every few seconds until the process exits. harmless during shutdown, but nothing logs it

**null handling**
- returns `nil` history after shutdown; handler `range`s it fine. nothing to change
