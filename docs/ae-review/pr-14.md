## Improvement suggestions

**Worth doing before the real model lands**
- Add a finish reason to `Message`, so a cut-off reply doesn't complete the workflow as if it were finished.
- Log failures in `Run`, or in the runner around it, so a failed run shows up outside the in-memory bus.
- Make `Agent` fields unexported so `NewAgent` is the only constructor, and a missing model or zero step limit can't reach `Run`.
- Replace `unknown message %v` with a message that names the cause.
- Emit an event for text the model sends alongside tool calls.

**Small tidy-ups**
- Collapse the five `workflow.failed` blocks into a local `fail` function.
- Remove `ToolCompleted`, the no-op `append`, the unused `step`, and either remove or unexport `ModelResponse`.
- Add a `Role` type, and rename `jsonfyIfNeeded`.
- Resolve empty and invalid args once per call.

**Tests**
- Replace the channel emitter with a slice recorder and shared helper. Removes the drains, timeouts and buffer sizing, and would shrink `agent_test.go` noticeably.
- Move `TestAgentRunBasic` and `TestAgentEmitErrorWhenModelErrors` to the `DeepEqual` style, with explicit model-call counts.
- Add a test for a cancel on the 10th turn, once you decide which reason it should report.
